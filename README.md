# Tanmay Udamale — Resume Website

## Included files
- `index.html`: portfolio content and navigation
- `style.css`: page layout, colors, responsive styles and mobile navigation

## Preview locally
Keep both files in the same folder and open `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in to GitHub and create a public repository named `tanmay-resume-website`.
2. Upload `index.html` and `style.css` to the top level of the repository.
3. Open the repository's Settings → Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish. Your site URL will be shown on the Pages settings screen.

## Before submitting
- Check that the name, course, college and email are correct.
- Add LinkedIn/GitHub profile links only if you want to share real profiles.
- Test the site on mobile and desktop.
- Paste the real live website URL and repository URL into the assignment report.
